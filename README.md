# 🔗 Shortify

Shortify is a simple and efficient URL Shortener application built using Node.js. It allows users to convert long URLs into short, easy-to-share links for better usability and cleaner link management.

## 🚀 Features

* Convert long URLs into short links
* Fast and simple URL shortening
* User-friendly interface
* Clean and responsive design
* Unique short URL generation
* Easy link sharing

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/KajalAhir23/Shortify.git
```

Move into the project folder:

```bash
cd Shortify
```

Install dependencies:

```bash
npm install
```

Start the server:

```bash
npm start
```

---

## ▶️ Run Locally

```bash
npm start
```

Open:

```text
http://localhost:3000
```

---

## 🎯 How It Works

1. User enters a long URL.
2. The application generates a unique short URL.
3. The short URL redirects users to the original website.
4. Users can easily copy and share the shortened link.
